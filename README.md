# Aura Komputer Digital - Company Profile Landing Page

## 🛠️ Teknologi & Dependencies

Proyek ini dibangun menggunakan teknologi berikut:

| Teknologi        | Versi/Keterangan | Kegunaan                |
| :--------------- | :--------------- | :---------------------- |
| **11ty**         | Latest           | Static Site Generator   |
| **Tailwind CSS** | v4               | Styling utility-first   |
| **Vite**         | Latest           | Build tool & Dev Server |

### Aset & Library Pihak Ketiga

- **Font:** [Plus Jakarta Sans](https://fonts.google.com/specimen/Plus+Jakarta+Sans) via Fontsource CDN.
- **Icons:** [Font Awesome](https://fontawesome.com/) & referensi gaya dari [Lucide Icons](https://lucide.dev/).
