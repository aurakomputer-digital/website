# Apa itu Mutasi Data Siswa?

Mutasi Data Siswa adalah proses perubahan data siswa yang dibuat secara manual. untuk siswa yang mengundurkan diri, pindah sekolah, siswa bermasalah, dikeluarkan dan lain - lain

---

# Input Mutasi Data Siswa

1. Klik tombol **<span class="text-green-600 font-bold">Tambah data Mutasi siswa</span>** di pojok kiri atas
2. Isi formulir dengan data yang benar
3. Klik tombol **<span class="text-green-600 font-bold">Simpan</span>**

![bg right:30% fit](https://raw.githubusercontent.com/aurakomputer-digital/obsidian-assets/main/20260728131857018.webp)

---

# Mengembalikan data mutasi siswa

untuk mengembalikan data mutasi siswa, klik tombol **<span class="text-green-600 font-bold">Kembalikan</span>** di masing masing baris data siswa
