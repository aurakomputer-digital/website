# Dashboard Absensi

Terdapat 2 jenis dashboard untuk **absensi guru**:

1. Dashboard **Pengelola** (Melihat Semua informasi absensi guru)
1. Dashboard **Personal** (Melihat informasi absensi milik diri sendiri)

---

# Dashboard Pengelola

- Filter per tanggal
- Rekap informasi absensi
- Trend statistik
- Daftar guru dengan keterlambatan terbanyak

- Rekap informasi absensi
- Trend statistik
