# Input Absensi Guru

untuk melakukan input data absensi guru, terdapat 2 cara:

1. Manual (per guru dan aktivitas)
2. Masal (Batch per tanggal dan aktivitas)

Gunakan Masal untuk mempercetak data absensi guru secara massal, gunakan manual jika data yang diinput tidak terlalu banyak atau di isi menggunakan mobile.

# Input Absensi Guru Secara Manual

untuk melakukan input data absensi guru secara manual, gunakan menu **Absensi Gugu** yang terdapat pada panel admin.

- Masukan data pada masing masing input dengan benar dan sesuai
- Data **Keterlambatan** dan **Pulang Lebih Cepat** Akan otomatis terkalkulasi
- Klik simpan untuk menyimpan data, dan otomatis akan tampil di riwayat absensi

# Input Masal

Dengan menggunakan input masal, pengisian absensi akan lebih cepat dan efisien, namun untuk kenyamanan gunakan _Perangkat dengan layar lebar_ seperti laptop untuk mempermudah pengisian
