# Apa itu Fitur Kelulusan Siswa?

Fitur **Kelulusan Siswa** adalah modul khusus untuk memproses siswa tingkat akhir yang telah menyelesaikan masa studi.

**Fungsi Utama:**

- Penetapan status **Lulus** atau **Tidak Lulus**.
- Menampilkan **Status Kelulusan** Siswa.
- Migrasi otomatis data siswa aktif menjadi **Data Alumni**.

![bg right:30% fit](https://raw.githubusercontent.com/aurakomputer-digital/obsidian-assets/main/20260728135952025.webp)

# Input data kelulusan Siswa

1. Masuk ke menu **kelola kelulusan siswa**
2. Klik tombol **tambah data kelulusan siswa**
3. Pilih jenis bisa **Manual per siswa**, **Batch per kelas** atau **Batch per tahun ajaran**
4. Pilih data **Siswa**, **Kelas** atau **Tahun Ajaran** yang di inginkan
5. Klik simpan

![bg right:30% fit](https://raw.githubusercontent.com/aurakomputer-digital/obsidian-assets/main/20260728150928833.webp)

# Menampilkan pengumuman kelulusan pada panel siswa

pada aplikasi ketika siswa login / masuk aplikasi bisa menginformasikan status kelulusan, ketika data sudah di inputkan

Untuk mengatur pengumuman kelulusan bisa di lakukan dengan cara:

1. Buka menu **Pengaturan** ➔ **Siswa** ➔ **Pengumuman Kelulusan**.
2. Cetang **Tampilkan pengumuman kelulusan**.
3. Sesuaikan **Tanggal mulai dan berakhir** pengumuman di tampilkan
4. Klik **Simpan**.
